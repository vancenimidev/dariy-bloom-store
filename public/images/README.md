# Product images

Drop your product photos into this folder using the filenames below.
They are served at `/images/<filename>` and picked up automatically.
Until a photo exists, the store shows a branded brown & gold placeholder.

Recommended: portrait JPGs at a 3:4 ratio (e.g. 1200×1600), under ~300 KB each.

| Product                        | Files                                                                 |
| ------------------------------ | --------------------------------------------------------------------- |
| Nimi Bubble Pants              | `nimi-bubble-pants-1.jpg`, `nimi-bubble-pants-2.jpg`, `nimi-bubble-pants-3.jpg` |
| Nonye Two-Piece Corporate Set  | `nonye-corporate-set-1.jpg`, `nonye-corporate-set-2.jpg`, `nonye-corporate-set-3.jpg` |
| Dinma Two-Piece                | `dinma-two-piece-1.jpg`, `dinma-two-piece-2.jpg`, `dinma-two-piece-3.jpg` |
| Ara Set                        | `ara-set-1.jpg`, `ara-set-2.jpg`, `ara-set-3.jpg`                     |
| Signature Ankara Midi Dress    | `ankara-midi-dress-1.jpg`, `ankara-midi-dress-2.jpg`, `ankara-midi-dress-3.jpg` |

`-1` is the main image (product cards, cart, hero); `-2` is shown on hover;
all three appear in the product detail gallery. To add or rename images,
edit `src/data/products.js`.
